## Project description

Leaf Doctor was my undergraduate project on plant-leaf photographs, completed from April 2022 to July 2022 during a B.Tech in Electronics and Communication Engineering at Kallam Haranadhareddy Institute of Technology. The original work used MATLAB, Python, and image processing to look for visible signs of disease.

The original source files were not available when I prepared a public copy, so the GitHub project is a later Python and OpenCV recreation of that study. It resizes a leaf photograph, reduces noise, separates the main green region, and estimates how much of that region differs from a green reference. The page states that this is a visual check, not a diagnosis, and it does not report an accuracy figure. The new code should be read as a current recreation, not as the 2022 MATLAB project itself.
