## Project description

This repository is the source code only. It is not the original final project report, slides, or submitted files.

The work studied plant-leaf photographs with image processing, from April 2022 to July 2022. The public copy is a later Python and OpenCV version of that study. It resizes a photograph, reduces noise, separates the main green region, and estimates how much of that region differs from a green reference. The result is a visual check. It does not name a disease and it does not report an accuracy figure.
